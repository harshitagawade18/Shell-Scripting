# Shell-Scripting 

A collection of Linux shell scripting automation and mini-project scripts created for practice and learning purposes.

## Scripts Included

- Guess The Number Game
- Website Connectivity Checker
- Backup Script
- Memory Usage Alert
- Disk Usage Alert
- Apache Server Status Checker
- File Listing Script
- User Validation Script
- Count Files in Specific Folder

## Technologies Used

- Linux
- Bash Shell Scripting
- Git & GitHub

## Purpose

To practice Linux shell scripting, automation, and basic system administration tasks through real-world mini projects.
